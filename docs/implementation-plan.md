# 羊咩咩 · Meadow Match

用户已授权制作精美的同类游戏并部署 GitHub Pages。本项目是原创网页游戏，采用 Vite、TypeScript、CSS 和 Web Animations API；目标为桌面与移动浏览器，后续微信移植另行适配。

## 范围与顺序

1. 纯逻辑引擎：遮挡、7格暂存、三消、撤回、移出、可验证洗牌、胜负、确定性关卡。
2. 原创牧场背景与12种牌面；响应式界面、卡牌飞行、弹性落位、消除粒子、胜利庆祝；支持减少动画。
3. 10个渐进关卡、每日挑战、本地进度、图鉴、说明、声音开关与重开。
4. 单元与浏览器测试、截图检查、生产构建。
5. 独立新 GitHub 仓库、Pages 工作流、正式地址检查。

## 验收条件

- 所有关卡均有可重放的7格限制内解法；洗牌保持所有牌的数量，并考虑卡槽与移出区。
- 快速连点不重复取牌；第7张先结算消除，再判负；撤回恢复完整操作前状态。
- 桌面与移动布局无横向溢出，玩法和弹窗可通过键盘操作，减少动画设置有效。
- 声音在用户交互后启用；进度仅保存在当前浏览器；不展示虚构在线排行榜。
- Pages 部署成功，生产页面和主要静态资源实际可访问。

## 验证

Vitest 覆盖引擎和生成器；Playwright 覆盖完整通关、道具、导航、存档、每日挑战、移动布局、减少动画与控制台错误；保留桌面和移动截图。自动测试与实际手机人工验收分别报告。

## 不规则排布优化

按用户反馈移除居中矩形逐层堆叠，改为有空洞、分叉、独立侧边深堆的不对称布局。牌块保持端正，排布使用手工坐标轮廓；镜像变化由关卡种子确定。保持每关牌数、既有存档与三消规则；额外验证同层牌不互相覆盖、所有牌在棋盘内、洗牌不改变几何结构、400个种子的合法解法和手机点选。新解锁的下层牌增加短促柔光提示，遵循减少动画设置。

## 参考图排布与卡死修复

根据用户后续提供的截图，将前一版分散轮廓替换为连续的七列底牌、跨格错位的局部盖牌，以及两个相对角落向上露背的深堆。初期四行底牌、后期八行，仍保持36至90张的渐进牌数；牌区高度随行数变化，保留原有原创美术。

动画报错或暂停时，旧版等待Animation.finished会让busy永久保持true。所有动画增加完成、取消、异常与超时四条释放路径；页面隐藏或开启减少动画时主动结束现有动效。选牌与洗牌通过finally同步最终状态、释放输入。牌区和卡槽按牌ID复用节点，粒子限额64并保证清理，揭牌和消除反馈使用transform与opacity，减少大区域阴影和滤镜动画。

验收包括：400个种子的完整合法解法与几何边界；连续底牌及跨格盖牌；10关真实点击通关；正常动效、快速输入、道具、键盘与存档；动画后端抛错、暂停和后台切换后的继续操作；完整通关时未变化的牌区节点不重建；4倍CPU降速下的78张牌局连续24次点击。部署后验证正式地址。

## 手机连续点选

用户反馈上一版等待完整动画后才接收下一张牌。取消选牌的全局动画锁：每次输入同步校验并提交，立即揭开下层牌，再由独立卡槽动效管理器并行播放飞行与三消。防重复依据牌ID与引擎状态；七格限制按输入顺序结算。三消只清理本组的动效节点，不恢复旧卡槽快照。道具与切关在当前动效结算后可用。

卡牌约230毫秒飞入卡槽，已有飞行在插入同类、重排、滚动或视口变化时从当前位置重定向。三消约170毫秒向上聚拢，给后续卡牌留出空间。单次飞行有800毫秒总截止时间，保留异常、暂停、减少动画及后台切换时的释放路径。

新增真实触控事件的手机模拟回归：三张连点且多牌同飞、36张整关不停顿通关、深堆同位置连续取牌、视口变化与落位、满槽拒绝后续输入及道具补救、多个暂停飞行的后台恢复、4倍CPU降速下24次连续触控。原有桌面、十关、道具、键盘和存档验证继续执行。
