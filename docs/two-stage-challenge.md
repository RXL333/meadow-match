# 双关挑战实施与验收

每轮只保留简单关、极难关。准备3套简单题、6套困难题供分配；失败重试沿用原题，完成或主动换组后再分配。收起旧十关地图和独立每日关，保留图鉴、道具、新手教程与连点。

## 实施

1. `levels.ts`定义两阶段与题库；`layouts.ts`实现12至18张的小牌阵，以及144至204张的紧密底牌、错位盖牌、深侧堆。
2. `game.ts`构造遵守七格限制的完整通关路线。难题使用12种图案，路线长期占用5至6格；用局部配对启发式试玩测量难度。固定经验证的题型与种子，轮换仅改变镜像与图案映射。优化遮挡查询，保护手机连点性能。
3. `storage.ts`隔离新版进度、保留旧设置；`main.ts`改双关流程、原题重试、换组、地图与通关提示，更新新手引导和README。
4. 验证所有题型合法通关、洗牌与道具、两关解锁、进度恢复、最密牌阵连点；部署后检查线上版本。

## 验收

- 前台始终两关，3套简单题与6套困难题可分配。
- 所有初始题均有无需道具、每步合法、不爆槽的完整通关路线；有效洗牌也保留合法路线。
- 困难题覆盖12种图案，验证路线最高占6格，主要步骤在5至6格。记录启发式试玩实际结果，不把机器人结果当真人通关率。
- 布局不越界，同层不重叠；失败可补救或原题重试。
- 类型检查、规则测试与受影响浏览器测试通过。手机测试明确为浏览器模拟。
